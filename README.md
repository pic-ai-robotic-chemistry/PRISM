# Nested Model–Guided Inverse Design of COFs with Programmable Circularly Polarized Luminescence for Information Encryption

This repository contains the code implementation accompanying the paper.

## Skills

| Skill | Function |
|---|---|
| [cof-monomer-extraction](skills/cof-monomer-extraction/SKILL.md) | Extract COF monomers from the literature and look up their SMILES. |
| [cpl-predict-skill](skills/cpl-predict-skill/SKILL.md) | Prepare spectral data, train a CNN, and evaluate CPL spectrum predictions. |
| [cof-inverse-design](skills/cof-inverse-design/SKILL.md) | Search for red-phase fabrication parameters that meet a target CPL response. |
| [cpl-message-encoding](skills/cpl-message-encoding/SKILL.md) | Encode and decode messages using colour-based Morse and base-4 CPL intensity digits. |

Each `SKILL.md` lists its dependencies and usage commands.
